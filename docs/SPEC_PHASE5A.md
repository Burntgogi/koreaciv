# 5a단계 제작 명세 — 지도 층(불가사의·자원·기반시설)과 흠 고치기

상위 문서: `docs/DESIGN.md` §6–§7, `docs/PLAN_NEXT.md`. 앞 단계 명세: `docs/SPEC_PHASE1.md`, `docs/SPEC_PHASE3.md`.

이 단계는 **이미 받아 둔 원자료만** 쓴다. 새 자료는 다른 작업자가 동시에 모으고 있고 5b에서 붙인다.

## 0. 작업 구역

| 경로 | 권한 |
|---|---|
| `data/raw/` (단 `data/raw/layers/` 제외), `data/build/econ/` | 읽기만 |
| `data/raw/layers/`, `data/build/layers/`, `pipeline/collect_layers*.py`, `docs/LAYERS_DATA_REPORT.md` | **건드리지 않는다.** 다른 작업자의 구역이고 작업 도중이라 내용이 바뀐다 |
| `pipeline/build_layers.py`(새로), `pipeline/lib/`, 기존 `build_*.py`, `validate.py` | 만들고 고친다 |
| `site/` | 고친다 |

`data/raw/` 아래 파일은 신뢰할 수 없는 입력으로 다룬다. 압축은 빌드 임시 폴더에 풀고, 읽는 Python은 원자료 폴더를 작업 디렉터리로 삼지 않는다.

## 1. 공통 규칙

- 숫자와 위치는 모두 원자료에서 온다. 손으로 좌표나 값을 넣지 않는다.
- **위치 정밀도**를 항목마다 적는다: `point`(원자료 좌표), `area`(경계 폴리곤의 중심), `county`(주소에서 시군구까지만 알아내 그 시군구의 인구 가중 중심 칸에 놓음). 주소에서 시군구도 못 알아내면 싣지 않고 빠진 수를 보고한다. 외부 지오코딩 서비스는 쓰지 않는다.
- 주소 → 시군구 대응은 1단계의 현재 행정구역 이름표와 `crosswalk`로 한다. 옛 이름(예: 광주광역시 ○구)은 현재 코드로 옮긴다.
- 선정 규칙은 JSON 안에 한국어 문장으로 넣고 연감이 그대로 보여준다. 규칙은 원자료 필드만으로 재현 가능해야 한다("유명해서" 같은 손 선정 금지).
- 한 칸에 여러 항목이 겹치면 값이 큰 것 하나를 그리고 나머지는 툴팁·패널의 목록에 넣는다.
- 원자료를 열어 보고 명세대로 만들 수 없는 항목은 만들지 말고 이유를 보고한다.

## 3. 흠 고치기 (`PLAN_NEXT.md` L2·L9·L11·L12)

1. **광역시 비율 지표**: 특별·광역시 도시 패널에서 고용률·실업률·재정자립도가 "자료 없음"으로 나오는 대신 자치구 값의 범위를 "자치구 52.1–63.4%"처럼 보여준다(자치구 수와 기준 시점 포함). 합치거나 평균하지 않는다. 세종처럼 단일 값이 있는 곳은 그대로.
2. **집값**: `data/raw/econ/`에 실거래 건별 원자료가 있으면 도시·시군구별로 최근 12개월 **전체 거래**의 중위값(㎡당 매매가, 매매가, 전세 보증금)과 거래 건수를 직접 계산해 `housing`을 바꾼다. 원자료가 건별이 아니면 지금 방식을 유지하고 보고한다. 설명 문구도 맞춘다.
3. **독도 동쪽 줄무늬**: 높은 배율에서 보이는 희미한 줄의 원인을 찾아 고친다.
4. **다른 브라우저**: Playwright의 Firefox와 WebKit으로 첫 화면, 도시 패널, 렌즈 하나, 새 층을 열어 오류 없이 그려지는지 확인한다. 설치가 안 되면 무엇이 막혔는지 보고한다.

## 4. 화면

- **층 켜고 끄기**: 불가사의 / 자원 / 기반시설(역·공항) / 도로·철도 선을 따로 켜고 끄는 조작부. 기본값은 불가사의·자원 켜짐, 도로·철도 선 켜짐(옅게), 역은 확대했을 때만.
- **아이콘**: 캔버스에 직접 그린다(도형 또는 글리프). 외부 이미지·폰트·CDN 없음. 종류마다 모양과 색이 달라 전국 화면에서도 구분돼야 하고, 도시 깃발·시도 이름과 겹치면 깃발이 위에 온다.
- **국립공원**: 켜면 공원이 덮는 칸에 옅은 테두리나 빗금.
- **툴팁·패널**: 아이콘을 누르면 이름, 종류, 값과 단위, 기준 연도, 위치 정밀도, 출처. 같은 칸의 다른 항목 목록.
- **도시·시도 패널**: 그 도시(시도)에 있는 불가사의·자원·기반시설 목록 구역을 더한다.
- **검색**: 국립공원, 세계유산, 원전, 국가산업단지, 공항 이름으로도 찾을 수 있다.
- **연감**: 층마다 선정 규칙 문장, 건수, 출처, 기준 연도, 빠진 항목 수와 이유. `sources.json`에 새로 쓴 원자료를 더한다.
- 층 JSON은 `main.js`가 첫 화면을 그린 뒤 따로 불러온다(첫 화면이 느려지지 않게).

## 5. 검증 (`validate.py`에 추가, 기존 17개는 그대로 통과)

1. 층의 모든 항목이 육지 칸(또는 해상 공원의 섬 칸)에 놓여 있고, 칸의 소유 시군구가 항목의 소재 시군구와 같다(`point` 정밀도는 칸 중심에서 한 칸 거리 안).
2. 국립공원 수 = 경계 파일의 공원 수. 공원별 넓이 합을 출력한다.
3. 세계유산 수 = 원자료의 등재 건수.
4. 원전 가동 호기 수와 용량 합 = 원자료 합.
5. 유산 렌즈: 칸별 건수의 합 = 좌표가 유효한 건수(범위 밖으로 뺀 수 따로 출력).
6. 위치 정밀도별 항목 수, 주소 대응 실패로 빠진 항목 수를 출력한다.
7. 원자료의 빈 값이 0으로 들어간 곳이 없다.
8. 집값을 바꿨다면: 거래 건수 합 = 원자료 행 수(제외 조건별 수 출력).
