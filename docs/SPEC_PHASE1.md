# 1–2단계 제작 명세 — 헥스 지도와 인구 기반 층

상위 문서: `docs/DESIGN.md`. 이 문서는 그중 1단계(헥스 지도)와 2단계(인구 층)를 만들 수 있을 만큼 구체화한 것이다.
경제 산출(GRDP·일자리)은 범위 밖이다. 자리만 비워 둔다.

## 2. 인구 추가 수집 — `collect_population.py`

`collect_keyless.py`의 `collect_jumin`과 같은 방식이다(`jumin.mois.go.kr/ageStatMonth.do`에서 쿠키를 받고 `downloadCsvAge.do`에 POST, 응답은 CP949). 요청 사이 0.4초 이상 쉰다.

| 받을 것 | 방법 | 쓰임 |
|---|---|---|
| 읍면동 × 성별 × 5세, 최신 월 | 시군구 코드마다 한 번씩 읍면동 단위로 조회. 폼의 `sltOrgType`·`sltOrgLvl1`·`sltOrgLvl2` 조합은 페이지의 `selectHangkikcdListAjax.do`를 보고 맞춘다 | 헥스 인구밀도, 연령 렌즈 |
| 시군구 × 성별 × 5세, 2020–2025년 각 12월 | 시도마다 한 번씩 × 6개 연도 | 인구 시계열, 증감 |

읍면동 조회가 막히면 멈추지 말고 시군구 자료로 진행하고, 무엇이 안 됐는지 보고한다. 과거 연도는 당시 행정구역 코드로 나오므로 §3.4의 대응표로 현재 코드에 맞춘다.

## 3. 세계 만들기 — `build_world.py`

### 3.1 좌표

- 투영: EPSG:5179. 계산은 미터로 한다.
- 지도 범위: 경도 124.5–132.0°, 위도 33.0–38.95°를 투영한 사각형에 여백 20 km.
- 화면 단위: 헥스 외접원 반지름 2,800 m = 25단위 (1단위 = 112 m). JSON에는 화면 단위만 쓰고, `world.json`에 `meters_per_unit`와 좌상단 원점의 EPSG:5179 좌표를 적는다. y는 아래로 증가한다.

### 3.2 격자

- 뾰족한 쪽이 위. 열 간격 √3·R, 행 간격 1.5·R, 홀수 행은 반 칸 오른쪽으로 민다.
- 칸 번호 = `row * cols + col`. 이웃 6칸을 구하는 함수를 Python과 JS에 같은 규칙으로 둔다.
- 예상 크기는 약 134열 × 150행이다. 실제 값은 범위에서 계산한다.

### 3.3 칸 속성

칸마다 중심과 그 주변을 고르게 덮는 **표본점 37개**(중심 + 육각 고리 3겹)를 찍고, 각 점이 어느 행정동에 속하는지 찾는다. 점-다각형 판정은 `shapely`의 STRtree로 한다.

| 필드 | 규칙 |
|---|---|
| `owner` | 표본점 37개 중 19개 이상이 대한민국 행정동 안이면 육지. 가장 많은 점이 속한 시도의 번호. 아니면 −1 |
| `county` | 육지 칸에서 가장 많은 점이 속한 시군구의 번호 |
| `land_frac` | 대한민국 땅에 떨어진 점의 비율 (0–1). 밀도 계산의 분모 |
| `foreign` | 대한민국 땅이 아니고 Natural Earth 국가 다각형(북한·중국·일본) 안의 점이 과반이면 1. 지형만 그린다 |
| `elev`, `elev_sd` | 칸 안 SRTM30+ 표본의 평균과 표준편차 (m). 육지 칸은 0 m 이상인 표본만 쓴다 |
| `water` | 0 육지 / 1 먼바다(평균 수심 200 m 초과이고 육지 옆이 아님) / 2 연안 / 3 호수 (Natural Earth 호수 안) |
| `relief` | 0 평지 / 1 구릉(`elev_sd` ≥ 60) / 2 산(≥ 180) / 3 고봉(평균 ≥ 1,000) |
| `cover` | 이번 단계는 0(미정)으로 채운다. 필드와 분류표만 만든다 |

기복 기준값은 초안이다. 빌드 후 분포를 보고 평지:구릉:산이 대략 35:40:25가 되게 조정하고, 최종 값과 근거를 `world.tables.relief`에 문장으로 적는다. 작은 섬(울릉도·독도·백령도·흑산도 등)이 과반 규칙 때문에 사라지면, 칸 안에 다른 육지 칸이 없는 유인도에 한해 "표본점 1개 이상"으로 낮추는 예외를 두고 그 규칙도 적는다. 독도는 반드시 한 칸으로 나와야 한다.

북한 땅과의 경계(휴전선)는 `owner ≥ 0`인 칸과 `foreign = 1`인 칸이 맞닿은 변으로 그린다.

### 3.4 행정구역

- 시도 16개, 시군구 256개를 경계 파일에서 그대로 읽는다. 목록을 손으로 적지 않는다.
- `pipeline/lib/crosswalk.py`: 과거 코드 → 현재 코드 대응표. 최소한 광주·전남 통합, 군위군의 대구 편입(2023-07), 강원·전북 특별자치도 코드 변경, 부천시 일반구 설치를 다룬다. 과거 자료에 있는데 대응표에 없는 코드는 조용히 버리지 말고 빌드 오류로 낸다.
- 시도 이름표: 시도마다 가장 큰 육지 덩어리의 중심에 놓을 위치·각도·크기를 계산한다.

### 3.5 강

Natural Earth 강 중 대한민국 범위에 드는 것을 화면 단위 꺾은선으로 넣는다. 이름은 한국어로 바꾼다(한강, 낙동강, 금강, 영산강, 섬진강, 임진강, 북한강, 남한강 등). 1:10m에 없는 강은 이번 단계에서 넣지 않는다.

## 4. 지역 집계 — `build_regions.py`

### 4.1 도시 정의

시군구 256개를 다음 규칙으로 도시로 묶는다. 규칙은 코드로 쓰고 결과 목록을 `data/build/cities_check.csv`로 내보내 눈으로 확인할 수 있게 한다.

1. 이름이 `…구`인 시군구는 같은 시도 안의 구끼리 한 도시다(서울, 부산, 대구, 인천, 대전, 울산). 대구의 군위군, 부산의 기장군, 인천의 강화군·옹진군처럼 광역시 안의 군은 따로 도시로 둔다.
2. `수원시 장안구`처럼 `…시 …구` 꼴은 앞의 시로 묶는다.
3. 전남광주통합특별시 안의 광주 자치구들은 `광주`로 묶는다. 경계 파일의 이름만으로 판별이 안 되면 시군구 코드 범위로 판별하고, 어떻게 했는지 보고한다.
4. 세종은 한 도시, 제주시·서귀포시는 각각 도시다.
5. 나머지 시·군은 각각 한 도시다.

### 4.2 도시 필드

```
id, name, full, sido, kind(특별시|광역시|특례시|시|군), capital(수도|도청소재지|없음),
x, y, cell, footprint[칸 번호], sgg[시군구 코드],
population, households(자료가 없으면 생략), pop_series{연도: 인구}, growth_5y,
age{mean_est, median_est, under15, working, over65, women_20_39}, extinction_index,
pyramid{male[21], female[21]}, ranks{population, growth, over65, extinction}, peers[5]
```

- `x, y`: 읍면동 인구로 가중한 중심. 그 점이 자기 영토 밖이면 가장 가까운 자기 칸의 중심으로 옮긴다. 읍면동 자료가 없으면 넓이 중심.
- `mean_est`, `median_est`: 5세 계급의 중간값으로 계산한 추정치다. 이름에 "추정"을 붙인다.
- `extinction_index`: 20–39세 여성 ÷ 65세 이상 인구. 단계 구분은 0.5 미만 위험, 0.2 미만 고위험.
- `peers`: 인구 규모(로그)와 고령 비율이 가장 가까운 도시 5곳.
- 수도·도청 소재지는 작은 표로 직접 적고, 출처가 수작업임을 연감에 밝힌다.
- 경제 필드(`yields`, `jobs`, `gdp`)는 넣지 않는다. 프런트엔드는 이 필드가 없으면 해당 구역을 "자료 준비 중"으로 표시한다.

`states.json`(시도)과 `nation.json`(전국)도 같은 인구 필드로 만든다.

## 5. 렌즈 — `build_lenses.py`

읍면동 값을 칸에 내릴 때는 표본점을 쓴다. 한 읍면동의 인구는 그 읍면동에 떨어진 표본점 수에 비례해 칸들에 나눈다. 표본점이 하나도 없는 작은 동은 중심이 놓인 칸에 전부 준다. 나눈 뒤 전국 합이 원자료와 한 명도 어긋나지 않아야 한다.

| id | 이름 | 정의 | 단위 | 척도 | 방향 |
|---|---|---|---|---|---|
| `density` | 인구밀도 | 칸 인구 ÷ (칸 넓이 × `land_frac`) | 명/km² | 로그 | 중립 |
| `growth` | 인구 증감 | 2020-12 대비 최신 월 변화율 (시군구) | % | 발산, 0 중심 | 중립 |
| `over65` | 고령 인구 | 65세 이상 비율 | % | 선형 | 중립 |
| `under15` | 유소년 인구 | 0–14세 비율 | % | 선형 | 중립 |
| `age` | 평균연령(추정) | 5세 계급 중간값 평균 | 세 | 선형 | 중립 |
| `extinction` | 소멸위험지수 | 20–39세 여성 ÷ 65세 이상 | 지수 | 구간 5단계 (1.5↑, 1.0, 0.5, 0.2, 그 미만) | 높을수록 좋음 |
| `sex_ratio` | 청년 성비 | 20–39세 여성 100명당 남성 | 명 | 발산, 100 중심 | 중립 |

비율 렌즈는 읍면동 자료가 있으면 읍면동 단위로, 없으면 시군구 단위로 칠한다. 색 범위는 육지 칸 값의 2–98 백분위다. 인구가 0인 칸은 비율을 계산하지 않고 "자료 없음"으로 둔다.

## 7. 프런트엔드 — `site/`

원본 usaciv의 코드·그림·문구를 가져오지 않는다. 구조만 참고해 새로 쓴다. 화면 문구는 한국어다.

```
site/index.html
site/css/style.css
site/js/main.js          초기화, 자료 불러오기, 상태(URL 해시)
site/js/hex.js           격자 수학: 칸 ↔ 좌표, 이웃, 점 → 칸
site/js/camera.js        이동·확대, 화면 ↔ 세계 변환
site/js/render/terrain.js  바다·육지·기복·강·경계
site/js/render/lens.js     렌즈 색칠
site/js/render/banners.js  도시 깃발
site/js/ui/…             상단 띠, 툴팁, 도시·시도 패널, 렌즈 선택, 범례, 검색, 미니맵, 연감
```

### 7.1 지도 그리기

- 캔버스 하나에 그린다. 지형은 화면 밖 캔버스에 미리 그려 두고 이동할 때는 복사만 한다. 확대 비율이 바뀌면 다시 그린다. 기기 픽셀 비율을 반영한다.
- 층 순서: 바다(먼바다·연안 2색) → 외국 땅(채도 낮은 회갈색, 기복만) → 대한민국 땅(표고에 따른 초록–황토 바탕, 구릉은 작은 언덕 무늬, 산은 삼각 봉우리, 고봉은 눈 덮인 봉우리) → 호수·강 → 시군구 경계(가는 선, 확대했을 때만) → 시도 경계(굵은 선) → 휴전선(점선) → 렌즈 색 → 도시 깃발 → 시도 이름.
- 렌즈가 켜지면 지형의 채도를 낮추고 그 위에 렌즈 색을 덮는다. 기복 무늬는 비쳐 보이게 둔다.
- 확대 범위: 전국이 한 화면에 드는 수준부터 칸 하나가 화면에서 60 px쯤 되는 수준까지. 휠은 커서 위치 기준 확대, 끌기는 이동, 두 손가락 확대, 더블클릭 확대, 방향키 이동.

### 7.2 도시 깃발

- 이름과 인구를 담은 작은 띠를 도시 칸 위에 그린다. 인구는 `965만`, `12.3만`처럼 만 단위로 적는다.
- 겹침 처리: 인구가 큰 도시부터 놓고, 이미 놓인 깃발과 겹치면 그 확대 수준에서는 숨긴다. 확대하면 더 많이 보인다. 전국 화면에서는 대략 25개 안팎이 보이면 된다.
- 수도는 별, 도청 소재지는 작은 표식을 붙인다.

### 7.3 상호작용

| 동작 | 결과 |
|---|---|
| 칸 위에 커서 | 툴팁: 시도·시군구, 표고, 지형, 켜진 렌즈의 값 |
| 도시 깃발 또는 도시 영토 클릭 | 도시 패널: 인구, 6년 시계열 꺾은선, 인구 피라미드(남·여 5세 계급), 고령·유소년 비율, 소멸위험지수와 단계, 순위, 닮은 도시(누르면 이동). 영토를 강조선으로 두른다 |
| 도시가 없는 칸 클릭 | 그 칸의 도시 패널 (모든 육지 칸은 어느 도시에 속한다) |
| 시도 이름 클릭 | 시도 패널: 같은 인구 지표 + 소속 도시 목록(인구순) |
| 상단 띠 | 전국 인구, 고령 비율, 소멸위험지수, 자료 기준 시점. 누르면 전국 보고서 |
| 렌즈 선택 | 아래쪽 띠에서 고르고, 범례에 색 단계·단위·기준 시점·출처 |
| 검색 (`/`) | 도시·시도 이름으로 찾아 이동. 초성 검색까지는 하지 않아도 된다 |
| 미니맵 | 현재 보이는 범위 표시, 클릭으로 이동 |
| 연감 | 지형 규칙(`world.tables`), 렌즈 정의, 출처 목록(`sources.json`)을 보여준다 |
| URL 해시 | 위치·확대·렌즈·선택한 도시를 담아 새로고침해도 유지 |

패널의 경제 구역은 "자료 준비 중"으로 비워 둔다. 화면 너비 700 px 이하에서는 패널이 아래에서 올라오는 시트가 된다.

## 8. 검증 — `validate.py`

빌드 끝에 자동으로 돌고, 하나라도 어긋나면 0이 아닌 코드로 끝난다.

1. 시군구 인구 합 = 시도 인구 합 = 전국 인구 = 원자료의 전국 행.
2. 칸에 나눈 인구의 합 = 전국 인구 (오차 0).
3. 도시 인구 합 = 전국 인구. 모든 시군구가 정확히 한 도시에 속한다.
4. 모든 시군구가 칸을 하나 이상 가진다. 못 가진 시군구가 있으면 목록을 내고, 가장 많이 겹치는 칸을 넘겨주는 보정 규칙을 적용한 뒤 다시 검사한다.
5. 육지 칸 수 × 칸 넓이가 남한 넓이(약 100,400 km²)의 ±3% 안.
6. 독도·울릉도·백령도·마라도(또는 가파도)·제주가 육지 칸으로 존재한다.
7. JSON 배열 길이가 모두 `cols × rows`.

## 9. 확인 방법과 보고

- `python -m http.server`로 `site/`를 띄워 실제로 열어 본다. 가능하면 헤드리스 브라우저로 전국 화면, 서울 확대 화면, 소멸위험 렌즈 화면을 찍어 `docs/screenshots/`에 둔다. 브라우저를 못 띄우면 그 사실을 보고한다.
