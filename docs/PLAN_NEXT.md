## 3. 순서

1. 5a 제작(Claude Opus 5.5)과 5b 수집(Codex gpt-6.2-sol)을 동시에 시작한다. 작업 구역은 겹치지 않는다.
2. 수집 보고서(`docs/LAYERS_DATA_REPORT.md`)를 검토해 5b 제작 명세를 쓴다.
3. 5b 제작: 지형(토지피복·강·호수·갯벌) → 공식값(L1–L5) → 나머지 층 → 렌즈.
4. 단계마다 `validate.py`를 다시 돌리고 화면을 확인한다.

원칙은 그대로다: 공식 출처, 손으로 넣은 숫자 없음, 빈 값은 0이 아님, 인증키·로그인·신청이 필요한 자료는 받지 않고 목록으로만 남김.

## 9. 토지피복을 도엽 통계로, 인천공항을 공항철도 역으로 (2026-11-27, 두 판 공용)

- **칸 토지피복 (두 판 같음)**: 기후에너지환경부 「세분류 토지피복지도 도엽단위 현행화 통계」(공공데이터포털 15150509, 공공누리 제1유형, `data/raw/layers5/files/p2-15150509.csv`, `pipeline/lib/cover_sheets.py`). 원자료 36,261행 = 도엽 18,538개의 기준년도별 행(17,723개 도엽은 2023·2024년 기준 두 행). 규칙: 도엽마다 기준년도가 가장 늦은 행 하나 — 이 파일에서는 모두 2024년 기준(2025년 제작) 행.
- **도엽 테두리**: 8자리 = 위도 정수 2자리 + 경도 끝자리(4–9 → 124–129°, 0–2 → 130–132°) + 1:50,000 번호 01–16(1°×1° 안 15′, 북서에서 행 우선) + 1:5,000 번호 001–100(1.5′, 북서에서 행 우선), 세계측지계(GRS80). 검산: 세분류 41개 면적 합 ÷ 테두리 타원체 넓이가 18,538개 가운데 18,252개에서 0.01% 안(중앙값 0.0002%). 번호를 남쪽부터 읽으면 대개 0.3–1.5% 어긋난다. 해안 도엽의 '해양수·갯벌 아닌 몫'을 행정경계와 견주면 옮기지 않은 테두리가 가장 맞고(평균 차 0.060), 옛 동경측지계만큼(위 +10″·경 −8″) 옮기면 0.093 으로 나빠진다. 특별도곽은 원자료로 찾았다: 33605–33608 남 6′, 33609–33614 남 6′·서 5′(제주 동부·마라도), 37012 북 4.5′(울릉). 33609(3도엽)·33614(1도엽)는 땅이 아주 작아 옮긴 값의 확인이 약하다.
- **칸에 나누기 (두 문장)**: 도엽마다 해양수·갯벌을 뺀 세분류 면적을 도엽과 칸이 겹치는 대한민국 행정경계(행정동) 안 넓이에 비례해 칸에 나누고, 행정경계와 겹치지 않는 도엽은 도엽과 칸이 겹치는 넓이에 비례해 나눈다. 칸 비율은 칸에 모인 면적의 비율이고, 도엽 통계가 하나도 닿지 않는 육지 칸(옹진군 1칸)만 ESA WorldCover 로 채워 `cover_src 'esa'` 로 적는다. 갯벌을 나누지 않는 까닭: 도엽의 갯벌 합은 2,247 km² 인데 행정경계로 자른 국가 통계의 갯벌은 35 km² — 땅 칸에 얹으면 습지가 두 배가 된다(나누면 1.26%, 통계 1.27%).
