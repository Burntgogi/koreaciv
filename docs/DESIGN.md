# koreaciv 설계서 — 대한민국을 전략 게임 지도로

기준일 2026-11-26. 원본: <https://karpathy.ai/usaciv/> ("usaciv — the United States as a strategy game").

## 1. 원본이 하는 일

실제 미국을 4X 전략 게임 지도처럼 그린 정적 웹사이트다. 서버 없이 `index.html` + ES 모듈 + `data/*.json` 11개로 돌아가고, 모든 숫자가 공공데이터에서 나온다. 사이트의 JS와 데이터 파일을 내려받아 구조를 확인했다.

| 요소 | 원본의 내용 | 규모 |
|---|---|---|
| 헥스 지도 | 캔버스에 그린 육각 타일. 타일마다 소유 주·카운티, 표고, 기복(평지/구릉/산/봉우리), 물(바다/연안/호수), 토지피복 | 117×90 = 10,530칸, 육지 4,807칸 |
| 도시 | 대도시권(CBSA)마다 깃발. 인구, 5대 산출, 산업별 일자리·GDP, 소득·임대료·집값, 순위, 닮은 도시 | 524개 |
| 산출(yields) | 식량·생산·금·과학·문화. 금은 GDP, 나머지는 산업별 취업자 수 | 5종 |
| 렌즈 | 카운티 통계를 헥스에 칠하는 단계구분도 (인구·소득·집값·빈곤·학력·통근·신앙·재난 등) | 7묶음 19종 |
| 자원 | 타일 위 아이콘: 발전소(원전·수력·석탄·가스·풍력·태양광·배터리), 광산, 셰일 | 21종 618곳 |
| 기반시설 | 도로·철도 선, 항만(물동량), 공항(탑승객) | 항만 136, 공항 368 |
| 군사 | 기지·훈련장, 주별 병력·국방비 | 660곳 |
| 불가사의 | 국립공원, 연구대학, 역사 랜드마크 | 52곳 |
| 교역로 | 지역 간 화물 흐름 상위 구간 | 40개 구간 |
| 연감(Almanac) | 모든 숫자의 정의·출처·기준연도·선정 규칙 | 출처 31건 |
| 기타 | 주·도시 검색, 미니맵, 링크/이미지 공유, 주 패널, 국가 산출 보고서 | |

설계에서 배울 점은 세 가지다.

1. **규칙이 데이터 안에 있다.** "표고 표준편차 85 m 이상이면 구릉", "1,000 MW 이상 석탄발전소만 표시" 같은 선정 규칙이 JSON에 문장으로 들어 있고 연감이 그대로 보여준다.
2. **출처마다 파일·URL·수집시각·sha256을 남긴다.** 재현과 갱신이 가능하다.
3. **없는 값은 0이 아니라 "자료 없음"이다.** 비공개 처리된 값을 추정으로 메우면 추정이라고 표시한다.

한국판도 이 세 가지를 그대로 따른다. 코드와 그림은 새로 만든다(원본의 라이선스가 확인되지 않았다).

## 2. 한국판의 범위

- 대상: 대한민국 전역. 제주·울릉도·독도·서해 5도 포함.
- 북한·중국·일본 땅은 원본의 캐나다·멕시코처럼 **지형만 그리고 통계는 싣지 않는다**. 휴전선은 경계선으로 표시한다.
- 언어: 한국어 기본, 영어 병기(이름·단위 필드를 `ko`/`en`으로 분리).
- 형태: 원본과 같은 정적 사이트. 빌드 파이프라인(Python)이 `data/*.json`을 만들고 프런트엔드는 읽기만 한다.

## 3. 지도

### 3.1 격자

| 항목 | 값 | 근거 |
|---|---|---|
| 투영 | EPSG:5179 (Korea 2000 / Unified CS) | 국토지리정보원·통계청 표준. 전국 단일 좌표계 |
| 범위 | 경도 124.0–132.0°, 위도 33.0–39.0° | 백령도·독도·마라도 포함, 북쪽은 평양 아래까지 |
| 헥스 | 뾰족한 쪽이 위, 외접원 반지름 2.8 km (마주보는 변 사이 4.85 km, 넓이 20.4 km²) | 남한 넓이 약 10만 km² ÷ 20.4 ≈ 4,900칸. 원본의 육지 4,807칸과 같은 밀도 |
| 격자 크기 | 약 134열 × 145행 ≈ 19,400칸 | 바다가 많아 원본의 약 2배. JSON 크기는 감당 가능 |

서울(605 km²)이 약 30칸, 제주도가 약 90칸, 울릉도가 3–4칸이 된다. 서울 자치구 하나는 한 칸보다 작을 수 있으므로 렌즈 값은 읍면동 자료가 있으면 읍면동에서, 없으면 시군구에서 넓이 가중으로 헥스에 내린다.

### 3.2 지형 규칙

원본 규칙을 한국 지형에 맞게 다시 잡는다. 기준값은 실제 분포를 보고 빌드 때 확정한다.

| 층 | 분류 | 규칙(초안) | 자료 |
|---|---|---|---|
| 물 | 육지 / 먼바다 / 연안 / 호수·댐 | 중심+꼭짓점 7점 중 4점 이상이 육지면 육지. 수심 200 m 이내 또는 육지 옆이면 연안 | 행정경계, SRTM30+ 수심 |
| 기복 | 평지 / 구릉 / 산 / 고봉 | 헥스 안 표고 표준편차 60 m↑ 구릉, 180 m↑ 산, 평균 1,000 m↑ 고봉 (원본은 85 / 260 / 2,700 m. 한국 산은 낮고 촘촘해서 낮춘다) | SRTM30+ → 국토지리정보원 DEM으로 교체 |
| 피복 | 활엽수림 / 침엽수림 / 혼효림 / **논** / **밭·과수** / 초지 / 습지 / 시가지 / 나지 | 헥스 안 최대 넓이 분류 | 환경부 토지피복지도 중분류 |
| 특수 | **갯벌** | 연안 헥스 중 갯벌 넓이가 30% 이상 | 해양수산부 갯벌 공간자료 |
| 선 | 강 | 국가하천 전부 + 주요 지방하천 (한강·낙동강·금강·영산강·섬진강 수계) | 환경부 하천망, 초안은 Natural Earth |

논과 갯벌은 원본에 없는 한국 고유 타일이다. 미국 지도의 옥수수 지대가 하는 역할을 한국에서는 호남·충남의 논이 한다.

### 3.3 행정 체계

수집한 2026-10-01 행정동 경계에서 확인한 현재 체계는 **시도 16개, 시군구 코드 256개, 행정동 3,559개**다. 광주와 전남이 `전남광주통합특별시`(시군구 27개)로 합쳐져 있다. 과거 통계는 17개 시도 기준이므로 파이프라인에 연도별 행정구역 대응표(`crosswalk`)를 둔다. 군위군의 대구 편입(2023), 강원·전북의 특별자치도 전환, 부천시 일반구 부활 같은 변경도 같은 표로 처리한다.

| 원본 | 한국판 | 수 |
|---|---|---|
| 주 (state) | 시도 | 16 |
| 카운티 | 시군구 (일반구 포함) | 256 |
| 도시 (CBSA 대도시권) | **시·군 단위 도시.** 특별·광역시와 그 자치구는 한 도시로 묶고, 일반구가 있는 시도 한 도시로 묶는다 | 약 160 |

한국에는 CBSA 같은 공식 대도시권 통계 단위가 없다. 시·군을 도시로 쓰면 주민등록·GRDP·사업체 통계가 그대로 맞아떨어진다. 수도권·부울경 같은 광역권은 도시가 아니라 **광역권 테두리 오버레이**로 따로 보여준다(국토교통부 대도시권 광역교통 관리 특별법의 5대 대도시권 정의 사용).

## 4. 산출

2026-11-26 개정. 처음에는 원본처럼 산업별 종사자 수로 잡으려 했으나, 전국 시군구 × 산업 대분류 종사자 표를 키 없이 받지 못했다. 반면 시군구 GRDP는 16개 시도 전부에서 경제활동 19분류로 받았다(도시 166/167). 그래서 **다섯 산출을 모두 GRDP의 산업별 부가가치로 계산한다.** 단위는 원이고, 모두 생산지 기준이다.

| 산출 | 원본 | 한국판 (GRDP 경제활동별 부가가치, 당해년가격) |
|---|---|---|
| 🌾 식량 | 농림어업 취업자 | 농업, 임업 및 어업 |
| ⚙️ 생산 | 제조+건설+광업 취업자 | 제조업 + 건설업 + 광업 |
| 💰 금 | GDP | 지역내총생산(시장가격) 전체 |
| 🔬 과학 | 전문과학기술+정보 취업자 | 정보통신업 + 사업서비스업 |
| 🎭 문화 | 예술·오락 취업자 | 문화 및 기타서비스업 |

알고 쓰는 한계가 있다. 연감에 그대로 적는다.

- GRDP 19분류는 KSIC 대분류보다 거칠다. "사업서비스업"은 전문·과학·기술 서비스에 사업시설관리·임대가 섞여 있고, "문화 및 기타서비스업"은 예술·스포츠·여가에 협회·수리·개인서비스가 섞여 있다.
- 시도마다 작성하므로 기준연도가 다를 수 있다(대부분 2023, 세종 2024 잠정). 도시마다 `gdp_year`를 둔다.
- 금액이라 물가·산업 구조의 영향을 받는다. 종사자 수와 달리 자본집약 산업(정유, 반도체)이 있는 도시가 크게 나온다.

- 광업은 사업체가 적어 여러 시군구에서 비공개다. 광업만 비공개인 곳은 생산을 제조업 + 건설업으로 내고 "광업 비공개 제외"로 표시한다. 제조업이나 건설업이 비공개면 생산은 "자료 없음"이다.

종사자 수는 산출이 아니라 도시 패널의 보조 정보로 쓴다(전산업 합계와 제조업은 확보, 대분류 전체는 수집 중). 농가·임가·어가 인구와 논·밭 면적도 패널의 식량 구역에 보조로 싣는다. 패널의 나머지 값은 1인당 총급여(국세청, 주소지 기준), 아파트 매매·전세 중위가격(국토교통부 실거래가), 고용률·실업률(지역별고용조사)로 채운다.

`data/raw/` 아래 28건, 약 110 MB. 파일마다 `data/raw/manifest.json`에 출처·URL·수집시각·sha256·크기를 기록했다. `python pipeline/collect_keyless.py`로 다시 받을 수 있다.

## 9. 파이프라인과 데이터 계약

```
pipeline/
  collect_keyless.py   키 없는 원자료 수집 (작성·실행 완료)
  collect_kosis.py     KOSIS·data.go.kr·SGIS OpenAPI 수집 (키 필요)
  crosswalk.py         연도별 행정구역 코드 대응 (17→16 시도, 편입·승격)
  build_world.py       투영, 헥스 격자, 지형 규칙 → world.json
  build_regions.py     시도·시군구·도시 집계, 산출, 순위 → nation/states/cities.json
  build_lenses.py      렌즈 값 → 헥스 넓이 가중 → lenses.json
  build_layers.py      자원·기반시설·불가사의·교역로 → 각 json
  validate.py          합계 검증 (시군구 합 = 시도 = 전국), 결측·음수·범위 검사
data/raw/              원자료 + manifest.json (git 에는 manifest 만)
site/                  정적 사이트: index.html, js/, css/, data/*.json
```

산출 파일은 원본과 같은 모양으로 맞춘다. 화면 구성 요소를 원본과 1:1로 대응시킬 수 있다.

| 파일 | 내용 |
|---|---|
| `world.json` | 격자, 칸별 소유 시도·시군구·표고·물·기복·피복, 분류 규칙 문장, 강 |
| `nation.json` / `states.json` / `cities.json` | 전국·시도·도시의 인구, 산출, 산업별 일자리·GRDP, 순위, 닮은 도시 |
| `lenses.json` | 렌즈 정의와 칸별 값 |
| `resources.json` / `infrastructure.json` / `wonders.json` / `trade.json` / `frontier.json` | 지도 층. `frontier.json`이 원본의 `military.json` 자리 |
| `sources.json` | 출처 목록: 기관, 라이선스, 기준연도, 파일·sha256 |

Python 의존성은 `pyproj`, `shapely`, `numpy`, `rasterio`(토지피복 래스터용)다. 현재 환경에는 설치돼 있지 않다.

## 10. 한국 자료에서 조심할 것

- **행정구역이 자주 바뀐다.** 2026년의 광주·전남 통합처럼 시도 단위도 바뀐다. 모든 통계를 수집 시점 코드로 저장하고 대응표로 현재 코드에 맞춘다.
- **기준이 섞인다.** 주민등록 인구(등록지), 총조사 인구(거주지), 사업체 종사자(사업장), GRDP(생산지), 급여(주소지)가 서로 다른 기준이다. 세종·과천·화성처럼 통근 유입이 큰 곳은 1인당 값이 왜곡된다. 원본처럼 지표마다 "어디서 센 값인지"를 적는다.
- **시군구 GRDP는 시도마다 따로 작성한다.** 공표 시점과 기준연도가 다를 수 있다. 도시마다 `gdp_year`를 따로 둔다.
- **비밀보호로 가려진 칸.** 사업체조사는 사업체 수가 적은 칸을 가린다. 0으로 채우지 않는다.
- **주기가 긴 자료.** 종교는 10년, 학력·통근은 5년 주기다. 렌즈마다 기준연도를 보여준다.
- **라이선스.** 공공누리 유형이 자료마다 다르다(출처표시 / 상업적 이용 금지 / 변경 금지). `sources.json`에 유형을 적고, 변경 금지 자료는 가공 없이 쓸 수 있는지 먼저 확인한다. admdongkor 정리본의 재배포 조건도 확인이 필요하다.
- **인코딩.** data.go.kr CSV는 대부분 CP949, 일부만 UTF-8이다. 수집 단계에서 판별해 UTF-8로 통일한다.
- **지명 표기.** 동해·독도 표기를 쓴다. 배경 지도를 외부 타일에서 가져오지 않고 직접 그리므로 표기를 통제할 수 있다.
