- **개편과 결측**. 2020년 12월 원표의 광주 1,450,062 + 전남 1,851,549 = 3,301,611명으로 전남광주 과거 시계열과 일치한다. 대구 2,418,346 + 당시 경북 군위 23,256 = 2,441,602, 경북 2,639,422 − 23,256 = 2,616,166으로 양쪽이 일치한다. 화성시 855,248명도 현행 도시의 2020년 값에 그대로 남는다. 인천 제물포·영종구의 미공표 출산율은 툴팁에 ‘자료 없음’으로 표시됐다. 서울 광업 결측은 산업 집계에서 null로 남는다. 01·16은 그 값을 사용자에게 설명하는 과정에서 발생한다.
- **조작**. 기존 Chromium 실입력 검사에는 클릭·드래그·휠·핀치, 층 및 세부 선택, 범례 가리키기·끌기·터치, 링크 복사, 1600×900 PNG 디코딩, 패널 ⓘ 가리키기·고정·Esc, 검색 입력 중 단축키 억제와 네 폭 배치가 포함됐다. 추가 검사에서 렌즈 33개 각각의 활성 ID·범례, 1920px의 보고서 8개와 모든 모드, 검색 결과 선택을 확인했다. 정상 요청의 추가 검사에서 페이지 예외·콘솔 오류는 0건이었다. 390·768·1920px 캡처도 확인했다.
- **해시**. v/lens/item/route/city/state/report/ly/hide/off/on에 대표 정상값 하나씩을 두고, 선택을 비운 상태에서 키 존재 조합 2¹¹개 모두를 실제 파서에 넣었다. 대상 우선순위·렌즈 존재·검사 대상 세부/묶음 상태의 불일치 0건. 2,048번의 새 탭 로딩이나 모든 문자열·카메라 좌표의 전수 검사는 아니다. 추가로 기존 탭 이동, 빈 값, 미등록 ID, 비수치 카메라, 음수 배율, 정리된 렌즈 ID, 옛 층 키를 주소창에 해당하는 실제 URL로 확인했다. 11에 차이가 있다.
- **네트워크·시간**. 로컬 무압축 HTTP, 헤드리스 Chromium, 1280×800 새 컨텍스트 3회. 지도 캔버스 첫 테두리 그리기 시점까지 완료한 요청은 매회 29건(문서 포함), 본문 3,719,201바이트, 시각은 272.5 / 250.1 / 256.7ms였다. 1920×1080 측정에서 ready 뒤 두 번째 animation frame 시점은 355.8ms, 그때까지 지연 층을 포함해 완료한 요청은 34건, 본문 4,930,998바이트, 브라우저 추정 전송량 4,941,198바이트였다. 측정 도중의 동시 수정 전 표본을 포함한다. 첫 테두리 시각은 픽셀이 사용자 화면에 제시된 시각의 근사치다.
- **이동 성능**. 1920×1080에서 실제 드래그 50스텝 동안 관측한 animation frame 간격 103개는 중앙 16.7ms, P95 33.3ms, 최대 33.4ms였다. 휠 30회 동안 97개는 같은 중앙·P95·최대였다. 이벤트 사이 대기도 포함된 간격이다. 순수 렌더 CPU 시간이나 실제 전화기의 프레임 속도로 일반화할 수 없다.
- **출처 무결성**. 단일 경로 레코드와 WMS 개별 타일에서 246개 파일 레코드의 길이·SHA-256이 일치했다. 디렉터리를 가리킨 돼지 출처도 내부의 단일 CSV를 열면 다이제스트가 맞았다. 출처의 ‘미확인’은 실제로 36건으로 집계됐다. 사이트 안의 연감은 기관·시점·허락·근거 링크를 제공하며 지형 범례도 OSM 기여자를 표시한다.

## 미확인과 재현 범위

수집 보고서에 적힌 약관의 적용 예외, 운영자의 별도 이용허락, 사이트의 영리 운영 또는 외부 공개 여부는 확인하지 않았다. 스크린리더 실기 발화, 실기기 GPU·네트워크, 모든 수집 표 전체 셀, 악성 입력 실행도 검사 범위 밖이다. 현재 사이트 파일에서 실행된 공격을 발견한 것으로 해석해서는 안 된다. 이번 세션에서 다른 작업자가 수정한 원전 배치·대학 배율·값 옆 주석의 진행 중 상태는 결함 수에서 제외했다.

Windows 프로젝트 루트에서 다음 순서로 독립 검사를 반복할 수 있다. 스크립트는 로컬 서버만 사용한다. 기존 조작 검사는 결과 문서 쓰기 함수를 비활성화해 기존 QA 보고서를 보존했다. 원자료는 격리 모드에서 CSV·JSON·스프레드시트 등 데이터로만 읽었다.

```powershell
python -I -B -m http.server 18972 --bind 127.0.0.1 --directory site
# 다른 터미널
python -I -B -X utf8 tools/audit/samples.py
python -I -B -X utf8 tools/audit/browser.py
python -I -B -X utf8 tools/audit/details.py
python -I -B -X utf8 tools/audit/provenance.py
python -I -B -X utf8 tools/audit/validator_sensitivity.py
python -I -B -X utf8 -c "import runpy,sys,site; sys.path.append(site.getusersitepackages()); runpy.run_path('pipeline/validate.py',run_name='__main__')"
python -I -B -X utf8 -c "import runpy,sys,site; sys.path.append(site.getusersitepackages()); m=runpy.run_path('tools/qa_interaction.py')['main']; m.__globals__['write_md']=lambda *_:None; sys.argv=['qa','chromium']; m()"
```

브라우저 측정은 요청에서 지정한 Playwright 헤드리스 Chromium을 사용했다. 별도의 Browser 스킬은 설치 목록에 없었다. 실행 로그는 `tools/audit/`의 samples, browser, details, provenance, validation, interaction 텍스트 파일에 있다.
