# 5e단계 제작 명세 — 돼지 시군구 값과 보훈대상자 렌즈

상위 문서: `docs/PLAN_NEXT.md`, `docs/SPEC_PHASE5A.md`(공통 규칙), `docs/SPEC_PHASE5C.md`. 기존 검증 59개는 그대로 통과해야 한다.

원본(karpathy.ai/usaciv)과 맞대어 보니 원본에 있고 한국판에 없는 자료 항목은 보훈대상자(Veterans) 렌즈였다. 돼지는 2019년 값을 최신 시군 값으로 바꾼다. 두 자료 모두 공공데이터포털에서 로그인 없이 받아 두었다.

## 1. 입력 (읽기만, 신뢰할 수 없는 입력으로 다룬다)

| 경로 | 내용 |
|---|---|
| `data/raw/layers3/pig/15147317_pig_herd_by_county_2018_2026.csv` + `manifest.tsv` | 가축위생방역지원본부 「전국 시군별 일반돼지 사육규모 현황」. cp949. 열: 순번, 품종, 시도, 시군, 년도, 전체호수, 전체두수, 규모 구간별 호수·두수. 2018–2026년, 2026년 135행, 전체두수 합 11,128,880 |
| `data/raw/layers3/veterans/1509857x.csv`(17개) + `manifest.tsv` | 국가보훈부 「시도별 시군구별 보훈대상자 인원현황」(세종은 읍면동별). 열: 연도, 분기, 시도, 시군구, 연번, 대상구분_상, 대상구분_하, 합계, 본인, 선순위유족. 2021년 1분기–2026년 3분기 |

manifest.tsv 열: 데이터 번호, 제목, URL, sha256, 바이트. `sources.json`에 싣는다.

## 2. 돼지

- 최신 연도(2026)의 `전체두수`를 시군 값으로 쓴다. 시군 이름이 `부산`, `대구`, `인천`, `광주`, `대전`, `울산`, `세종`처럼 광역시 이름이면 그 광역시 도시의 값이다. 이름 → 현재 시군구 코드는 기존 `crosswalk`와 이름표로 한다. 못 찾은 행은 싣지 않고 수와 이름을 출력한다.
- 원자료에 없는 시군은 "자료 없음"이다(0이 아니다). 원자료에 0으로 적힌 값은 0이다.
- 기존 2019년 돼지(`pigs`) 층·도시 패널·시도 합계를 이 값으로 바꾼다. 선정 규칙(상위 N)은 그대로. 기준 연도와 출처 표기를 바꾸고, "일반돼지만 포함(종돈·흑돼지 등은 별도 자료라 빠짐), 방역 시스템 등록 농가 기준"이라는 설명을 규칙 문장에 넣는다.
- `resources.json`의 `unavailable`에서 돼지 항목을 뺀다.
- 기존 시도 단위 값(`livestock_pig_sido.csv`, 가축동향조사)과 시도 합을 비교해 차이 비율을 출력만 한다(조사가 달라 판정하지 않는다).

## 3. 보훈대상자 렌즈

- 가장 최신 (연도, 분기)을 쓴다. 파일마다 최신 분기가 다르면 파일별 기준 시점을 적고, 한 시군구에는 그 파일의 최신 분기를 쓴다.
- 시군구별 인원 = 그 시군구의 모든 `대상구분` 행의 `합계`를 더한 값. 원자료 설명대로 대상 사이에 중복이 있어 실제 인원보다 많을 수 있다. 이 문장을 렌즈 설명에 넣는다.
- 시군구 이름이 시도 이름이거나 `(합계)`·`합계`가 붙은 행은 시도 합계 행이므로 시군구 값에서 뺀다(시도 공식값 대조에만 쓴다). 파일을 열어 실제로 어떤 행이 합계인지 확인하고, 시군구 합과 합계 행이 맞는지 출력한다.
- 이름 정리: `강서구(서울)`, `고성군(강원)`, `군산시(전북특)`처럼 괄호가 붙은 이름, `수원시 장안구` 같은 일반구, 옛 구역(부천시 소사구 등)과 현재 구역이 같이 있는 경우를 `crosswalk`로 현재 256개 코드에 대응시킨다. 한 시군구가 두 파일에 나오면(대구 파일의 경북 시군 등) 값이 같은지 확인하고 하나만 쓴다. 다르면 소재 시도 파일의 값을 쓰고 출력한다.
- 세종은 읍면동 행을 더하거나 시 합계 행을 쓴다(둘이 맞는지 확인).
- 렌즈 `veterans`: 묶음 `people`, 이름 "보훈대상자", 값 = 인원 ÷ 주민등록 인구 × 1,000 (인구 천 명당 명). `higher_is` 중립. 시군구 단위.
- 도시·시도 패널에 인원과 천 명당 값을 싣는다(광역시는 자치구 합).
- 대응하지 못한 이름 수, 값이 없는 시군구 수를 출력한다.

## 4. 크기

사이트 JSON 합계는 5 MB 한도를 유지한다(현재 4.98 MB). 한도를 올리지 말고 줄일 곳을 찾아 맞춘다. 줄이는 방법은 값의 뜻을 바꾸지 않는 것만 쓴다(불필요한 자릿수, 중복 필드, 시군구 단위 렌즈를 칸 단위로 펼친 저장 등). 무엇을 줄였는지 보고한다.

## 5. 검증 (`validate.py`에 추가)

- E1 돼지: 층 값의 합(도시 대응된 것) + 대응 실패 값 = 원자료 2026년 합 11,128,880.
- E2 돼지: 원자료의 빈 값이 0으로 들어간 곳 없음.
- E3 보훈: 시군구 값의 합 = 원자료 시군구 행 합(중복 파일 제외 뒤). 시도 합계 행과의 차이를 출력.
- E4 보훈: 256개 시군구 가운데 값이 있는 수를 출력하고, 240개 미만이면 실패.
- E5 사이트 JSON 합계 < 5 MB.
